Interior Hero

Component: InteriorHero
Props:
  - eyebrow (Text)
  - title (Text, may contain an accent span)
  - copy (Rich Text component, Size variant)
Variants:
  - cc-center
Slots:
  - none
Notes:
  - Base is LEFT aligned; cc-center centres both the blocks and the text.
  - Eyebrow and copy are both optional: About has no copy, Home has no eyebrow.
  - Background and vertical padding come from the .section wrapper, so the
    same component works on a dark or a .cc-light section unchanged.
  - .interior-hero_accent consumes --primary-accent, so accent words in the
    heading flip Lichen/Moss with the section theme and need no variant.
  - The copy block wraps the Rich Text component rather than styling prose,
    so size stays a Rich Text variant.

Logo Wall

Component: LogoWall
Props:
  - title (Text)
Collection List:
  - source: Clients collection
  - fields: Name (Text), Logo (Image)
  - the img binds to Logo, the alt binds to Name
Variants:
  - none
Slots:
  - none
Notes:
  - Sits on a LIGHT section in the comps (Bone background) because the
    client logos are dark. The component sets no background of its own.
  - The heading is H4-sized and uses --primary-accent, so it is Moss on a
    light section and Lichen on a dark one.
  - 4-up on desktop, 2-up below 767px. The comp happens to show 16 logos
    in 4 rows, but nothing here assumes a count — the Collection List
    renders whatever the collection holds.
  - Cell proportion is 300 x 169 (measured). The logo is constrained
    inside the padded cell with object-fit, so a tight-cropped CMS upload
    and a padded export both sit correctly.
  - Logo colours are the brands' own and are deliberately NOT normalised
    to the palette.
  - Only 4 of the 16 marks ship as sample assets; the rest live in the CMS.
