Typography, color, spacing, buttons, forms, icons, cards and grid — the complete set of classes available to this project.

Typography

Headings scale fluidly with clamp() between 480px and 1440px. Use the semantic element for document structure and a .h1–.h6 class for visual size — <h3 class="h2"> is an h3 in the DOM that looks like an h2.

Heading one — 2.8 to 5.5rem

Heading two — 2 to 3.8rem

Heading three — 1.5 to 2.3rem

Heading four — 1.375 to 1.75rem

Heading five — 1.25 to 1.5rem

Heading six — 1.125 to 1.25rem

Transfer-safe ramp

Webflow rejects h1–h6 as class names, so anything pushed into the Designer uses the .text-* classes instead. They carry their own family, weight and leading, so they work on any element.

.text-display-xl .text-display-lg .text-display-md .text-heading-lg .text-heading-md .text-heading-sm

Body and supporting styles

Lede — a larger opening paragraph used to introduce a section. Muted by default so it sits below the headline in the hierarchy.

Body copy. The default paragraph size scales from 1rem to 1.125rem. Paragraphs carry a bottom margin in EM units so spacing stays proportional to the type size — do not remove it without reason.

Large body — .text-body-lg, the same fluid size as a default paragraph, for use on elements that are not <p>.

Small body — .text-body-sm, fixed at 0.875rem for dense UI text.

Themes

Seven --primary-* roles that every component consumes. Base is dark — the primary palette of this site. .cc-light on .page-wrapper or .section flips background, surface, text, border and accent together. In Webflow this is the Theme collection with a Base and a Light mode, applied to the cc-light combo — it cascades to descendants natively. Any property bound to a brand color instead of a --primary-* role will not flip. Buttons need no extra roles: fill is --primary-accent, label is --primary-background, and that reads correctly in both modes.

Spacing

Two scales. The fixed --space-* ramp below (rem, twelve steps measured across all nine page frames) drives utilities and layout padding — a utility must give the same gap wherever it lands. Separately, --margin-xs/sm/md/lg are em and are used only by type rules, so a heading's own bottom margin scales with its size. Grid gaps are px on MAST's names: Gap Main 40, Gap MD 24, Gap SM 10, Gap Button 16.

xs · 0.5rem · 8px — hairline gap
sm · 0.625rem · 10px — tight gap (Grid Gap)
md · 1rem · 16px — small gap
lg · 1.25rem · 20px — base unit (Global Padding)
xl · 1.5rem · 24px — card padding / list gap
2xl · 2rem · 32px — block gap
3xl · 2.5rem · 40px — block gap (large)
4xl · 3rem · 48px — stack gap
5xl · 4rem · 64px — section-internal gap
6xl · 5rem · 80px — section padding (small)
7xl · 6.25rem · 100px — wide gutter
